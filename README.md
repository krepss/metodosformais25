# FiadoFácil - Sistema de Controle de Fiado para Vendedores Ambulantes

## Descrição do Projeto

FiadoFácil é uma aplicação simples e prática desenvolvida para ajudar vendedores ambulantes
a controlar as vendas feitas a fiado. A ideia surgiu da necessidade de pequenos comerciantes
que não possuem ferramentas eficientes para registrar quem está devendo, quanto foi comprado,
e quando os pagamentos são feitos.

O sistema permite o cadastro de clientes, registro de vendas fiadas, pagamentos parciais ou totais,
e geração de relatórios com saldos atualizados. Com isso, o vendedor pode ter uma visão clara e organizada
das dívidas e recebimentos futuros.

## Objetivo

Criar uma aplicação acessível e de fácil uso, que funcione offline e permita ao vendedor ambulante:
- Registrar de forma segura seus clientes e suas dívidas;
- Acompanhar pagamentos;
- Gerar relatórios de devedores e valores pendentes.

## Público-alvo

Pequenos vendedores e ambulantes que desejam controlar suas vendas fiadas de forma prática, rápida e segura, usando um celular ou computador simples.

## Tecnologias Utilizadas

- Linguagem: JavaScript (HTML/CSS/JS)
- Armazenamento: Arquivo local `.json` ou `.csv`
- Interface: Simples, responsiva e offline
- Especificação Formal: Linguagem Z
- Documentação: README, Artigo Científico e Especificação Formal

## Requisitos

### Funcionais
- F1: Cadastro de clientes
- F2: Registro de vendas fiadas
- F3: Registro de pagamentos parciais ou totais
- F4: Exibição do saldo devedor por cliente
- F5: Geração de relatório de clientes devedores

### Não-Funcionais
- NF1: Disponível offline
- NF2: Interface acessível por celular
- NF3: Armazenamento seguro local
- NF4: Respostas rápidas (menos de 2 segundos)
- NF5: Exportação dos dados (formato CSV)
